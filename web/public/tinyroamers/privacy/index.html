Privacy Policy

Last updated: October 6, 2026 · Published as Dino Buddy until version 1.0

Tiny Roamers does not collect, store, transmit, sell or share any personal data.

Tiny Roamers shows an animated pixel creature (a “roamer”) on web pages. It comes as a Chrome extension and as a script that website owners can add to their own pages.

The Chrome extension

  • No data leaves your browser. The extension makes no network requests and contains no analytics, tracking or advertising code. Its fonts and images are inside the package.
  • Page content. To let the roamer walk on a page, the extension reads the position and size of elements on that page (for example headings, images and buttons). This happens only inside your browser, only while the roamer is shown, and nothing is recorded or sent anywhere.
  • Settings. Your choices (size, color, whether the roamer appears on every site, and sites where you turned it off) are stored with chrome.storage.sync. Chrome may sync them between your own signed-in browsers. The developer has no access to them.

Permissions

  • activeTab and scripting: show the roamer on the current tab when you ask for it from the extension's popup.
  • storage: remember your settings.
  • Access to all sites (optional, asked only if you turn on “On every site”): show the roamer automatically on pages you open. You can revoke it any time by turning the option off or from Chrome's extension settings.

The embeddable script

  • The script works the same way as the extension: it reads the layout of the page it is on, inside the visitor's browser, and sends nothing anywhere. It sets no cookies and stores nothing.
  • If a website loads the script from oguzhd.com, the visitor's browser downloads it like any other file. This server keeps no access logs for it and runs no analytics. Website owners who prefer can host the file themselves.

This website

This page and the Tiny Roamers home page load nothing from other servers and set no cookies.
